# GPT-5.6 Terra prompt profile

**Provenance:** official GPT-5.6 family guidance + official Terra positioning (intelligence/cost balance). The slightly stronger density bias is an operational heuristic, not a separate OpenAI prompt law. Checked 2026-09-06.

Apply the GPT-5.6 lean-prompt rules: one instruction once, decisive context, explicit autonomy/approval boundaries, hard constraints and success criteria, focused tools, proportionate validation.

For Terra, prefer a compact complete brief: remove decorative detail and low-value examples first, but never omit constraints/context needed for correctness. Avoid manual CoT.

Official sources: https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6 and https://developers.openai.com/api/docs/models
Runtime settings: `harness-openai.md`.
